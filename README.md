# Pontinho

Hama beads de mentirinha: escolha um desenho, toque numa cor e encaixe as continhas com aquele número. Quando todas estiverem no lugar, passe o ferrinho pra derreter e ficar tudo lisinho.

**Abrir:** https://amandanascibosso.github.io/fio-e-flor/

No iPhone: Compartilhar → Adicionar à Tela de Início. O progresso fica salvo no próprio celular.

Os desenhos ficam em `ARTS` dentro do `index.html` (`rows` com uma letra por continha, `.` é vazio; `pal` liga letra a cor; `cats` são as categorias).

O jogo antigo, Fio & Flor, está guardado na branch `fio-e-flor-jogo`.
